# TradeGate RSI (TradingView 지표)

TradeGate 체크리스트의 **RSI 시그널**(과매수·과매도, 다이버전스)과 **상위 타임프레임 추세**를 차트에서 바로 판단하기 위한 지표입니다.

## 지표 두 가지

| 파일 | 언제 쓰나 |
|---|---|
| [`tradegate_rsi_divergence.pine`](tradegate_rsi_divergence.pine) | **평소 쓰는 기본 RSI는 그대로 두고, 그 RSI 창 위에 다이버전스만 겹쳐 표시** (추천) |
| [`tradegate_rsi.pine`](tradegate_rsi.pine) | RSI 자체를 이걸로 바꿔 쓰기 (다이버전스 + 상위 TF RSI + 정보 패널 + 알림 전부 포함) |

### 기본 RSI 위에 다이버전스 겹치기 (추천)
1. 아래 "차트에 추가하기"대로 `tradegate_rsi_divergence.pine`을 추가 → 아래에 빈 창이 하나 생김
2. 그 창의 지표 이름 **TG 다이버전스** 옆 **⋯** → **창 이동**(Move to) → **위 창으로**(기존 RSI 창)
3. 이제 기본 RSI 선 위에 다이버전스 선과 라벨이 겹쳐 보임
4. 설정에서 **RSI 기간·소스를 기본 RSI와 같게** (기본 14, 종가) — 같아야 선이 RSI 선에 정확히 붙음
5. 위치가 어긋나 보이면 지표 이름 옆 ⋯ → **눈금 고정**(Pin to scale) → RSI와 같은 눈금 선택

- **켜고 끄기**: 지표 이름 옆 **눈 아이콘**
- 설정에서 상승 쪽 / 하락 쪽, 일반 / H 다이버전스, 라벨을 각각 켜고 끌 수 있음
- 설정 **표시 위치**를 "둘 다"로 하면 가격 차트(캔들)에도 함께 표시

## 차트에 추가하기

1. TradingView 차트 하단 **Pine 에디터**(Pine Editor) 열기
2. 기존 내용을 모두 지우고 위 파일 중 하나의 내용을 전부 붙여넣기
3. **저장** → **차트에 추가**(Add to chart)
4. 다음부터는 **지표** 메뉴 → **내 스크립트**에서 바로 추가할 수 있습니다

> 폰 앱에서는 Pine 에디터를 쓸 수 없어서 PC나 태블릿 웹에서 한 번 추가해야 합니다. 저장하면 폰 앱에서도 같은 지표가 보입니다.

## 화면 읽는 법

| 표시 | 뜻 |
|---|---|
| RSI 선 (굵은 선) | 흰색 = 중립, **빨강** = 과매수(70↑), **초록** = 과매도(30↓) |
| 노란 선 | RSI 이동평균. RSI가 위에 있으면 상승 모멘텀, 아래면 하락 모멘텀 |
| 파란 계단선 | **상위 타임프레임 RSI** (기본 4시간). 확정된 봉 값만 써서 나중에 바뀌지 않음 |
| 실선 + "상승 다이버전스" / "하락 다이버전스" | 반전 가능성 (오를 / 내릴 수 있음) |
| 점선 + "H 상승 다이버전스" / "H 하락 다이버전스" | 지금 추세가 계속될 가능성 (기본은 꺼져 있음) |
| 오른쪽 위 패널 | 현재 RSI 상태, 상위 TF RSI, 모멘텀, 마지막 다이버전스 |

다이버전스는 RSI 창과 **가격 차트에 함께** 선으로 그려집니다.

### 다이버전스 종류

다이버전스 = **가격과 RSI가 서로 반대로 움직이는 것**. 겉보기와 달리 힘이 빠지고 있다는 경고입니다.

| 차트 표시 | 가격 | RSI | 의미 |
|---|---|---|---|
| **상승 다이버전스** | 저점 ↓ | 저점 ↑ | 떨어뜨리는 힘이 약해짐 → **반등 가능** (롱 쪽) |
| **하락 다이버전스** | 고점 ↑ | 고점 ↓ | 올리는 힘이 약해짐 → **하락 가능** (숏 쪽) |
| **H 상승 다이버전스** | 저점 ↑ | 저점 ↓ | 상승 추세 속 눌림목 → **상승 계속** |
| **H 하락 다이버전스** | 고점 ↓ | 고점 ↑ | 하락 추세 속 반등 → **하락 계속** |

H는 히든(Hidden, 숨은) 다이버전스입니다. 반전이 아니라 추세가 이어진다는 신호예요.

## 꼭 알아둘 점

- **다이버전스는 늦게 확정됩니다.** 저점·고점이 확정되려면 그 뒤로 `피벗 오른쪽 봉 수`(기본 5개)만큼 봉이 지나야 해서, 선은 실제 저점보다 5봉 뒤에 나타납니다. 대신 **한 번 나타난 선은 사라지거나 바뀌지 않습니다.** 더 빨리 보고 싶으면 이 값을 2~3으로 줄이세요(대신 신호가 많아짐).
- **단독 진입 신호가 아닙니다.** 상위 타임프레임 방향, 지지·저항, 거래량과 함께 근거로 쓰세요. TradeGate 체크리스트에서 다른 근거와 함께 점수로 판단하는 용도입니다.
- 상위 타임프레임은 **현재 차트보다 큰 것**으로 고르세요. (예: 15분봉 → 1시간·4시간, 1시간봉 → 4시간·일봉)

## 추천 설정

| 매매 스타일 | 차트 | 상위 TF | 피벗 왼쪽/오른쪽 |
|---|---|---|---|
| 단타 | 5분 ~ 15분 | 1시간 | 3 / 3 |
| 스윙 | 1시간 ~ 4시간 | 일봉 | 5 / 5 (기본) |

노이즈가 많으면 설정에서 **과매수/과매도 근처 다이버전스만** 을 켜세요.

## 알림 걸기

차트에서 **알림 추가**(시계 아이콘) → 조건에서 **TG RSI** 선택 → 아래 중 하나 선택:

- 상승 다이버전스 / 하락 다이버전스
- H 상승 다이버전스 / H 하락 다이버전스
- 과매도 탈출 (RSI가 30을 위로 돌파)
- 과매수 이탈 (RSI가 70을 아래로 돌파)

빈도는 **봉 마감 시 한 번**(Once Per Bar Close)을 권장합니다.
