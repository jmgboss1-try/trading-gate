# TradeGate

코인 선물 진입 전 체크리스트 → **게이트(최소 점수 + 손절/증거금 조건)를 통과해야만 포지션 기록 가능** → 청산 복기 → 통계.

## 환경변수 (Vercel)

| 이름 | 용도 |
|---|---|
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | 데이터 저장 (Upstash Redis) |
| `ANTHROPIC_API_KEY` | AI 진입 검토 |
| `AI_MODEL` (선택) | 기본값 `claude-haiku-5-5` |

## 손익 계산 기준

- 입력 금액 = **투입 증거금**. 포지션 규모 = 증거금 × 레버리지 × 체결 비율
- 수수료 = 포지션 규모 × 편도 수수료(설정) × 2
- 청산 시 거래소 실현손익을 직접 입력하면 그 값이 우선
- 예상 청산가는 격리마진 근사치(유지증거금 무시)

## 화면

- 폰: 하단 탭바 + 가운데 `+` 버튼, 모달은 바텀시트
- 펼친 화면(폭 720px 이상): 왼쪽 사이드바, 분석 중엔 왼쪽 차트 / 오른쪽 입력
- 경첩으로 나뉜 듀얼 스크린: 왼쪽 화면 메뉴·차트, 오른쪽 화면 내용·입력
- Safari "홈 화면에 추가"로 앱처럼 실행 가능
