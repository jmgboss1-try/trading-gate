# TradeGate

코인 선물 매매 일지. 차트 분석 → (진입 여부와 무관하게) 기록 → 진입했다면 체결가·시간·배율·증거금 기록 → 청산 복기 → 통계.

## 흐름

| 상태 | 의미 | 다음 행동 |
|---|---|---|
| 📝 분석 | 분석만 기록 (진입 안 함) | 진입 기록 / 주문 걸어둠 / 결과(TP·SL 먼저·둘 다 아님) 기록 |
| ⏳ 지정가 대기 | 주문을 걸어둠 | 체결됨 → 진입 기록 / 미체결·취소 → 분석 일지 |
| 진행 중 | 체결됨 | 청산 기록 |
| 승 / 패 | 청산 완료 | 통계 |

- **게이트**(최소 점수 + 손절·목표 위치 + 청산가 + 증거금)는 진입 규칙. 분석 저장에는 필요 없음
- 게이트 미통과로 진입하면 막지 않고 **규칙 위반**으로 기록 → 통계에서 준수/위반 성과 비교
- 진입하지 않은 분석도 사후 결과를 남기면 **분석 적중률·놓친 기회**가 집계됨

## 환경변수 (Vercel)

| 이름 | 용도 |
|---|---|
| `APP_PASSWORD` | **필수.** 로그인 비밀번호. 없으면 앱이 잠긴 상태로 설정 안내만 표시 |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | 데이터 저장 (Upstash Redis) |
| `ANTHROPIC_API_KEY` | AI 진입 검토 |
| `AUTH_SECRET` (선택) | 세션 서명 키. 없으면 비밀번호에서 파생(비밀번호 변경 시 모든 기기 로그아웃) |
| `AI_MODEL` (선택) | 기본값 `claude-haiku-5-5` |

## 보안

- 모든 API(`/api/data`, `/api/positions`, `/api/images`, `/api/ai`)는 로그인 쿠키 필요
- 세션: 서명된 httpOnly 쿠키, 180일 유지
- 로그인 실패 IP당 15분에 10회 초과 시 잠금

## 저장 구조 (Upstash Redis)

| 키 | 내용 |
|---|---|
| `tg:pos` (해시) | 포지션 1건 = 필드 1개, 이미지는 id만 저장 |
| `tg:img:<id>` | 차트 이미지 1장 (압축 JPEG dataURL) |
| `tg:seed`, `tg:checklist`, `tg:settings` | 시드 / 체크리스트 / 게이트·수수료 설정 |
| `tg:positions_legacy_backup` | 구버전 데이터 원본 (첫 실행 시 자동 이전 후 보관) |

## 손익 계산 기준

- 입력 금액 = **투입 증거금**. 포지션 규모 = 증거금 × 레버리지 × 체결 비율
- 수수료 = 포지션 규모 × 편도 수수료(설정) × 2
- 청산 시 거래소 실현손익을 직접 입력하면 그 값이 우선
- 예상 청산가는 격리마진 근사치(유지증거금 무시)

## 화면

- 폰: 하단 탭바 + 가운데 `+` 버튼, 모달은 바텀시트
- 펼친 화면(폭 720px 이상): 왼쪽 사이드바, 분석 중엔 왼쪽 차트 / 오른쪽 입력
- 경첩으로 나뉜 듀얼 스크린: 왼쪽 화면 메뉴·차트, 오른쪽 화면 내용·입력
- Safari "홈 화면에 추가"로 앱처럼 실행 가능
